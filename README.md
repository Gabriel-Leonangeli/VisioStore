# 🌀 Visio Store

**Visio Store** es una aplicación web desarrollada con **Django** que permite gestionar visuales digitales, categorías y formatos de manera simple y ordenada.  
Su diseño está inspirado en una estética moderna, limpia y monocromática.

---

## 🚀 Características principales

- Creación y administración de **categorías** de visuales.  
- Registro de **formatos** de archivos.  
- Carga de **visuales** asociados a categorías y formatos.  
- Búsqueda y filtrado de visuales.  
- Interfaz responsive con **Bootstrap 5**.  
- Sistema de usuarios con registro, inicio de sesión y panel personalizado.

🧭 Guía rápida de uso

🔑 Registrate o iniciá sesión desde la página principal.

🖼️ En tu perfil, accedé a los botones para:

Crear nuevas categorías.

Registrar formatos.

Subir nuevos visuales.

🔍 Utilizá el buscador para filtrar visuales por nombre o categoría.

🧰 Desde tu perfil podés editar o eliminar tus visuales en cualquier momento.
